## 🎯 핵심 개선사항

### 1. 수익 최적화 전략

**진입 조건** (4가지 모두 충족):
```
✅ 거래량 급증: 평균 대비 2.5배 이상
✅ 가격 모멘텀: 0.15% ~ 1.5% 상승 중
✅ RSI 적정: 70 이하 (과매수 방지)
✅ 매도벽 확인: 매도 압력 1.5배 이하
```

**청산 조건** (7가지, 우선순위):
```
1️⃣ 손절: -0.5% (최우선)
2️⃣ 시간초과: 180초 (3분)
3️⃣ 빠른익절: 30초 내 +0.3%
4️⃣ 목표익절: +0.5%
5️⃣ 트레일링스톱: +0.8% 도달 후 0.15% 하락
6️⃣ 거래량급감: 진입 시 대비 50% 이하
7️⃣ 급락감지: 1분 내 -1% 이상
```

### 2. 실시간 학습 시스템

```python
매 거래마다 학습 → 파라미터 자동 최적화

승률 < 40% → 진입 조건 강화
승률 > 60% → 진입 조건 완화
PF < 1.0 → 익절 목표 상향
시간초과율 > 50% → 시간 제한 단축
```

## 🎓 핵심 개념

### 수익 전략

**기본 원리**: "Volume Spike + Price Momentum + Smart Exit"

- 거래량 급증 포착 (비정상 매수세)
- 가격 모멘텀 확인 (상승 시작)
- 빠른 진입, 더 빠른 청산
- 엄격한 손절 (-0.5%)
- 시간 제한 (최대 3분)

### 실시간 학습

**학습 사이클**:
```
거래 발생 → 기록 저장 → 메트릭 계산 → 
[10건 이상] → 파라미터 조정 (±5%) → 
파일 저장 → 다음 거래에 적용 ✅
```

**조정 예시**:
- 승률 35% → 거래량 임계값 ↑ (진입 조건 강화)
- PF 0.8 → 익절 목표 ↑ (더 큰 수익 추구)
- 시간초과율 60% → 시간 제한 ↓ (더 빠른 청산)
